# Flexbox-Froggy-Tutorial
Flexbox Froggy final project

We introduced the final project, a website incorporating HTML, CSS, and Flexbox. The student planned the site's layout, set up HTML files, applied CSS styling, and tested responsiveness by building a Flexbox Froggy Website.

The student learned:

• How to structure HTML layout elements effectively for a single-page web project.
• Core Flexbox alignment properties to organize content dynamically.
• Style web pages using CSS to create a clean, responsive layout.
